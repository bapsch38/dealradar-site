La communauté fait le radar

Tu as trouvé une pépite ?
Partage-la ici.

Une promo intéressante, un code de réduction ou un prix qui semble être une erreur ? Envoie les informations en quelques secondes pour les proposer à la communauté DealRadar.

Les détails de l’offre

Le titre, le prix et le lien marchand sont les informations essentielles. Les autres détails sont facultatifs mais utiles pour vérifier l’offre.

⚠️
Une erreur de prix n’est pas une garantie d’achat.Le marchand peut corriger le prix, limiter les commandes ou annuler la vente selon ses conditions. N’indique pas que l’offre est confirmée si tu ne l’as pas vérifiée.
Colle le lien de la fiche produit, pas seulement la page d’accueil du marchand. Seuls les liens HTTP(S) sont acceptés.
N’ajoute pas de données personnelles. Une capture ou un lien vérifiable aide la modération.

Comment ça marche ?

1
Remplis la fiche

Ajoute le produit, son prix et son lien direct. Le prix de référence est facultatif s’il n’est pas fiable.

2
Choisis comment envoyer

Avec GitHub, tu crées directement un signalement. Avec Telegram, copie le résumé puis colle-le au bot DealRadar.

3
Envoi en modération

La proposition est publiée dans la file communautaire. L’envoi via Telegram ne nécessite pas de compte GitHub, mais nécessite Telegram.

4
Vérification avant affichage

Une personne doit vérifier l’offre avant qu’elle soit considérée comme fiable ou reprise dans le catalogue.

Transparence : GitHub demande un compte pour créer une issue. L’option Telegram envoie la proposition dans la même file publique de modération via le bot, sans compte GitHub. Dans les deux cas, l’offre n’est pas automatiquement validée ni ajoutée au catalogue.
